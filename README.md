# Files

## Application 

* rain_2015.txt: rainfall data in Lancaster, UK
* app.R: R code for reproducing application I
* acf_app.eps: ACF plot for the data
* cc_app.eps: ZAGA control chart for the data
* ecdf_ZAGA_app.eps: empirical and fitted ZAGA distribution for the data
* table_ARL_app.txt: ARL performance of the ZAGA control chart for the data
* *.pdf - images above in pdf
